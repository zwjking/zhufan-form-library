# 筑范 · 装修施工管理标准表单库

> 面向装修公司（家装 / 公装中小型）的全流程标准表单库：**9 个业务阶段 · 220 张标准表单**（含 55 张检验批级验收记录），每张表都带用途、填报责任、填写要点、常见纠纷点、编制依据，可直接 A4 打印、存 PDF、导出 Word / Excel。

纯静态站点，零依赖，双击 `index.html` 即可运行。

---

## 二、功能

- **全文检索**：表名、字段名、用途、纠纷点都可搜
- **三维筛选**：业务阶段 × 使用角色 × 表格性质
- **A4 预览**：原尺寸呈现，适配打印
- **打印 / 存 PDF**：单张或多张批量
- **导出 Word**：可编辑，保留表格与签字栏
- **导出 Excel**：便于二次加工成台账
- **批量打包**：按当前筛选条件一键导出 N 张
- **收藏**：常用表置顶
- **标准页**：13 项现行国标 / 行标 / 部令 / 地方示范文本对照

## 四、新增一张表

在对应阶段的 `data/fN-*.js` 里 `window.FORMS.concat([ {...} ])` 追加一个对象即可，首页统计、筛选、批量导出会自动包含：

```js
window.FORMS = (window.FORMS || []).concat([{
  id: 'SG-XX-01',                       // 编号，阶段缩写-序号，全局唯一
  n: '表单名称',
  st: 'build',                         // 所属阶段（lead/survey/design/quote/prep/build/handover/after/internal）
  r: ['项目经理','工长'],              // 使用角色
  ty: '验收单',                        // 表格性质
  tg: ['检验批','验收'],               // 标签（首页常用标签取自这里）
  b: 'GB 50210-2018',                 // 编制依据（表头打印）
  p: '用途',                          // 为什么用这张表
  w: '填报责任',                      // 谁填、何时填、交给谁
  d: ['常见纠纷点1','常见纠纷点2'],    // 常见纠纷/踩坑
  t: ['填写要点1','填写要点2'],        // 填写要点
  m: [['工程名称',''],['验收日期','']],// 表头键值（成对，2 列网格）
  c: [{t:'验收项目',w:'24%'}, ...],   // 主表列（可选）
  rows: 8,                            // 主表留白行数（渲染会按区块数收缩）
  s: [                                // 附加区块
    {k:'check', title:'主控项目', items:['...']},
    {k:'kv',    title:'实测', m:[[k,v]]},
    {k:'text',  title:'结论', h:2}
  ],
  sg: ['施工班组长','质量员','监理工程师'], // 签字栏
  note: '备注说明'
}]);
```

## 七、技术说明

- 纯静态：HTML + CSS + 原生 JS，无框架、无构建、无依赖
- 数据用 `<script src>` 承载而非 `fetch(JSON)`，`file://` 协议下也能正常运行
- 一份 JSON 定义驱动四种输出：网页预览 / PDF 打印 / Word / Excel
